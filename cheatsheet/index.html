Master the Command Line

A comprehensive reference for the most powerful shell commands, organized for efficiency and beauty.

📂 Navigation

ls -laR
List all files, hidden ones, and subdirectories recursively.
cd -
Switch back to the previous working directory.
pushd / popd
Save current directory to a stack and return later.

🛠️ File Ops

cp -rv
Copy files with verbose output to see progress.
rmdir
Remove an empty directory safely.
ln -s [target] [link]
Create a symbolic link (shortcut) to a file.

📝 Text & Logs

grep -rnE "regex"
Powerful recursive search using Extended Regex.
awk '{print $1}'
Extract the first column of data from a file/stream.
sed -i 's/old/new/g'
In-place find and replace text within a file.
sort | uniq -c
Sort lines and count unique occurrences.

🐙 Git Mastery

git checkout -b [name]
Create and switch to a new branch instantly.
git log --oneline --graph
View a visual, condensed history of your project.
git commit --amend
Modify your last commit (useful for fixing typos).
git stash / pop
Temporarily save changes without committing.

🐳 Docker

docker ps -a
List all containers (running and stopped).
docker exec -it [id] bash
Enter a running container's terminal.
docker-compose up -d
Launch multi-container apps in detached mode.
docker system prune
Clean up unused images, containers, and networks.

🚀 Deployment

vercel --prod
Deploy your current directory to production.
vercel logs
Stream live deployment logs to your terminal.
gh repo create
Interactively create a new GitHub repository.

🔒 Permissions

chmod +x [file]
Make a script or file executable.
chown -R [user]:[group]
Change ownership of a folder recursively.
sudo !!
Repeat the last command but with sudo.

⚡ Pro Shortcuts

Ctrl + R
Reverse-search through your command history.
Ctrl + L
Clear the terminal screen instantly.
Tab / Double Tab
Auto-complete commands, paths, and options.

🛰️ ARP

arp -a
Display the ARP table (default mode).
arp -n
Show numeric IP addresses (no hostname resolution).
arp -v
Verbose output – more detail about operations.
arp -d <hostname|IP>
Delete the ARP entry for the specified host (requires root).
arp -s <hostname|IP> <mac_addr>
Create a static ARP entry mapping host to MAC address.
arp -i <interface>
Limit the operation to a specific network interface.
arp -H <type>
Specify the hardware type (default is ether).

🖥️ Wireshark / Tshark

tshark -i <iface>
Capture on the specified interface.
tshark -f <capture filter>
Apply a BPF capture filter (e.g., "tcp port 80").
tshark -Y <display filter>
Display filter (Wireshark syntax) applied while capturing.
tshark -w <file.pcap>
Write captured packets to a file.
tshark -r <file.pcap>
Read packets from a capture file.
tshark -c <count>
Stop after capturing a specific number of packets.
tshark -a duration:<seconds>
Autostop capture after given duration.
tshark -a filesize:<bytes>
Autostop when captured file reaches size limit.
tshark -s <snaplen>
Set snapshot length (bytes per packet).
tshark -n
Disable network name resolution for speed.
tshark -T fields -e <field> -E separator=,
Export selected fields as CSV.

📡 Nmap

nmap -sS <target>
TCP SYN (stealth) scan – default for privileged users.
nmap -sT <target>
TCP connect scan – works without raw sockets.
nmap -sU <target>
UDP scan – discover UDP services.
nmap -sV <target>
Service/version detection on open ports.
nmap -O <target>
OS detection (requires open & closed ports).
nmap -A <target>
Aggressive scan – -O -sV -sC -traceroute.
nmap -sn <target>
Ping scan – list hosts without port scan.
nmap -Pn <target>
Treat all hosts as up – skip discovery.
nmap -PE -PA80,443 -PS22 -PU53 <target>
Specify ICMP, ACK, SYN, UDP probes for discovery.
nmap -p 22,80,443 <target>
Scan only the listed ports.
nmap -p- <target>
Scan all 65535 ports.
nmap -F <target>
Fast scan – only common ports.
nmap -T4 <target>
Timing template 4 – faster but more aggressive.
nmap --max-retries 1 <target>
Reduce probe retries for speed.
nmap -oN scan.txt <target>
Normal (human‑readable) output to file.
nmap -oX scan.xml <target>
XML output for further processing.
nmap -oG grepable.txt <target>
Grep‑able output for quick parsing.
nmap --script=default <target>
Run the default set of NSE scripts.
nmap -sC <target>
Shortcut for --script=default.

🏓 Ping

ping -c 4 <host>
Send 4 ICMP echo requests and stop.
ping -i 0.2 <host>
Set interval between packets (seconds).
ping -s 128 <host>
Set packet size to 128 bytes (payload).
ping -W 3 <host>
Wait up to 3 seconds for each reply.
ping -t 64 <host>
Set TTL (time‑to‑live) to 64 hops.
ping -q <host>
Quiet output – only summary statistics.
ping -b <broadcast>
Send ping packets to broadcast address (requires root).
ping -D <host>
Print timestamps before each line (debugging).

🔍 Find

find . -name "*.txt"
Find files by exact name (case-sensitive).
find . -iname "*.txt"
Find files by name (case-insensitive).
find . -type f
Find only regular files (use d for directories).
find . -empty
Find empty files and directories.
find . -size +50M
Find files larger than 50 Megabytes.
find . -size -10k
Find files smaller than 10 Kilobytes.
find . -mtime -7
Find files modified in the last 7 days.
find . -atime +30
Find files accessed more than 30 days ago.
find . -mmin -60
Find files modified in the last 60 minutes.
find . -newer file.txt
Find files modified more recently than file.txt.
find . -user <username>
Find files owned by a specific user.
find . -group <groupname>
Find files owned by a specific group.
find . -perm 644
Find files with exact 644 permissions.
find . -perm /u=s
Find files with the SUID bit set.
find . -maxdepth 2
Limit search to current directory and 1 level down.
find . -mindepth 3
Start searching from at least 3 levels deep.
find . -path "*/dir/*"
Match pattern against the full path.
find . -name "*.log" -delete
Find and immediately delete matching files.
find . -type f -exec grep -l "TODO" {} \;
Execute a command on each found file individually.
find . -type f -exec chmod 644 {} +
Execute a command on all found files at once.
find . -name "*.txt" -o -name "*.md"
Logical OR: matches either condition.
find . ! -name "*.html"
Logical NOT: matches files that do not end in .html.
find . -path "*/node_modules*" -prune -o -print
Exclude a directory (e.g., node_modules) from the search.

🔍 Grep

grep "pattern" file
Search for a string or regex pattern in a file.
grep -i "pattern" file
Case-insensitive search.
grep -w "word" file
Match the exact whole word only.
grep -x "line" file
Match the exact whole line only.
grep -v "pattern" file
Invert match: show lines that do NOT contain the pattern.
grep -E "regex" file
Use Extended Regular Expressions (same as egrep).
grep -F "string" file
Treat pattern as fixed string, no regex (same as fgrep).
grep -o "pattern" file
Show ONLY the matching part of the line, not the full line.
grep -n "pattern" file
Prefix each matching line with its line number.
grep -c "pattern" file
Print only a count of matching lines.
grep -A 3 "pattern" file
Show 3 lines of context AFTER the match.
grep -B 3 "pattern" file
Show 3 lines of context BEFORE the match.
grep -C 3 "pattern" file
Show 3 lines of context AROUND the match (before and after).
grep --color=auto "pattern" file
Highlight the matched string in color.
grep -r "pattern" dir/
Recursively search all files in the directory.
grep -l "pattern" dir/*
Print only the names of files containing the match.
grep -L "pattern" dir/*
Print only the names of files that do NOT contain the match.
grep -H "pattern" file
Print the file name for each match (default for multiple files).
grep -h "pattern" file1 file2
Suppress file name prefixes on output.
grep -m 5 "pattern" file
Stop reading the file after 5 matches.

📝 Sed

sed 's/old/new/' file
Replace first occurrence of 'old' with 'new' on each line.
sed 's/old/new/g' file
Replace ALL occurrences globally on each line.
sed 's/old/new/2' file
Replace ONLY the 2nd occurrence on a line.
sed 's/old/new/ig' file
Case-insensitive global replacement.
sed -i 's/old/new/g' file
In-place edit (overwrites the original file directly).
sed -i.bak 's/old/new/g' file
In-place edit but create a .bak backup first.
sed '3s/old/new/g' file
Replace only on line 3.
sed '1,5s/old/new/g' file
Replace only on lines 1 through 5.
sed '/pattern/s/old/new/g' file
Replace only on lines that contain 'pattern'.
sed '3d' file
Delete line 3 from output.
sed '2,5d' file
Delete lines 2 through 5.
sed '/pattern/d' file
Delete lines that contain 'pattern'.
sed '/^$/d' file
Delete all empty/blank lines.
sed -n 'p' file
Print all lines (-n suppresses default output).
sed -n '5p' file
Print ONLY line 5.
sed -n '2,6p' file
Print lines 2 through 6.
sed -n '/pattern/p' file
Print lines matching 'pattern' (acts like grep).
sed 's/^[ \t]*//' file
Remove leading whitespace/tabs from lines.
sed 's/[ \t]*$//' file
Remove trailing whitespace/tabs from lines.
sed '3a\New Line' file
Append 'New Line' AFTER line 3.
sed '3i\New Line' file
Insert 'New Line' BEFORE line 3.
sed '3c\Replaced' file
Change/Replace the entire line 3 with 'Replaced'.

📡 Netcat

nc -l -p 1234
Listen on TCP port 1234 (default mode). Use -u for UDP.
nc host.example.com 1234
Connect to host on port 1234.
nc -vz host.example.com 20-30
Verbose port scan on range 20‑30.
nc -e /bin/bash -l -p 4444
Spawn a bind shell on port 4444 (requires root).
nc -c 'date' host.example.com 1234
Execute a command after connection and send output.
nc -u host.example.com 1234
Communicate using UDP rather than TCP.
nc -w 3 host.example.com 1234
Set a timeout of 3 seconds for connections.
