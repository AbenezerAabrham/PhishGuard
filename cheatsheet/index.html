Master the Command Line

A comprehensive reference for the most powerful shell commands, organized for efficiency and beauty.

📂 Navigation

ls -laR
List all files, hidden ones, and subdirectories recursively.
ls -a vs ls -A
Show all files (incl. ., ..) vs. almost all (excl. ., ..).
ls -r vs ls -R
Reverse sorting order vs. recursively listing subdirectories.
ls -s vs ls -S
Show allocated size vs. sort by file size descending.
ls -d vs ls -D
List directories themselves vs. format dired output.
ls -h vs ls -H
Human-readable sizes vs. follow command line symlinks.
ls -f vs ls -F
Do not sort (enable -a) vs. classify entries with trailing character (e.g. /, *).
cd -
Switch back to the previous working directory.
pushd / popd
Save current directory to a stack and return later.

🛠️ File Ops

cp -rv
Copy files with verbose output to see progress.
cp -r vs cp -R
Recursive directory copy (standard behavior).
cp -p vs cp -P
Preserve file attributes vs. copy symlink itself without dereferencing.
cp -i vs cp -I
Prompt before overwrite vs. prompt only if copying >3 files.
rmdir
Remove an empty directory safely.
ln -s [target] [link]
Create a symbolic link (shortcut) to a file.

📝 Text & Logs

grep -rnE "regex"
Powerful recursive search using Extended Regex.
grep -i vs grep -I
Case-insensitive search vs. ignore/skip binary files.
grep -l vs grep -L
List files WITH matches vs. files WITHOUT matches.
grep -r vs grep -R
Recursive search vs. recursive search following symlinks.
sed -e vs sed -E
Specify script expression vs. use Extended Regex syntax.
awk -F vs awk -v
Define custom field separator vs. assign external variable.
sort | uniq -c
Sort lines and count unique occurrences.

🐙 Git Mastery

git checkout -b vs git checkout -B
Create and switch vs. force create/reset and switch to branch.
git branch -d vs git branch -D
Delete merged branch vs. force delete unmerged branch.
git log -p vs git log -P
Show commit patch/diff vs. search using Perl-compatible regex.
git diff -w vs git diff -W
Ignore all whitespace changes vs. show whole function context.
git log --oneline --graph
View a visual, condensed history of your project.
git commit --amend
Modify your last commit (useful for fixing typos).
git stash / pop
Temporarily save changes without committing.

🐳 Docker

docker run -d
Run container in detached background mode.
docker run -p vs docker run -P
Publish specific port vs. publish all exposed ports dynamically.
docker ps -a vs docker ps -q
List all containers vs. quiet mode (only show IDs).
docker exec -it [id] bash
Enter a running container's terminal.
docker-compose up -d
Launch multi-container apps in detached mode.
docker system prune
Clean up unused images, containers, and networks.

🚀 Deployment

vercel --prod
Deploy your current directory to production.
vercel logs
Stream live deployment logs to your terminal.
gh repo create
Interactively create a new GitHub repository.

🔒 Permissions

chmod +x [file]
Make a script or file executable.
chown -R [user]:[group]
Change ownership of a folder recursively.
sudo !!
Repeat the last command but with sudo.

⚡ Pro Shortcuts

Ctrl + R
Reverse-search through your command history.
Ctrl + L
Clear the terminal screen instantly.
Tab / Double Tab
Auto-complete commands, paths, and options.

🛰️ ARP

arp -a vs arp -A
Display ARP table vs. alternative BSD-style / interactive display.
arp -n
Show numeric IP addresses (no hostname resolution).
arp -v vs arp -V
Verbose operation output vs. print utility version.
arp -d vs arp -D
Delete entry vs. use interface's hardware address for proxy ARP.
arp -s <hostname|IP> <mac_addr>
Create a static ARP entry mapping host to MAC address.
arp -i <interface>
Limit the operation to a specific network interface.
arp -H <type>
Specify hardware type (e.g., ether, ax25, pronet).

🖥️ Wireshark / Tshark

tshark -i vs tshark -I
Capture on specified interface vs. capture in wireless monitor mode.
tshark -f vs tshark -F
Apply a BPF capture filter vs. set output file format (e.g. pcapng).
tshark -r vs tshark -R
Read packets from file vs. apply a read-time display filter.
tshark -w vs tshark -W
Write raw packets to file vs. write with custom options.
tshark -c vs tshark -C
Stop after capturing count packets vs. load specific config profile.
tshark -s vs tshark -S
Set snapshot payload length vs. show status/updates.
tshark -n vs tshark -N
Disable name resolution vs. enable specific name resolution (e.g., m, n, t).
tshark -q vs tshark -Q
Quiet mode (no output to stdout) vs. extremely quiet (only print statistics at end).
tshark -d vs tshark -D
Decode as selector vs. print list of available capture interfaces.
tshark -v vs tshark -V
Print tshark version vs. verbose packet details/protocol tree.

📡 Nmap

nmap -sS vs nmap -sT vs nmap -sU vs nmap -sV
TCP SYN (stealth) scan vs. TCP Connect vs. UDP scan vs. Service Version detection.
nmap -sn vs nmap -sP
Ping scan (skip port scan) vs. legacy ping scan equivalent.
nmap -p <ports> vs nmap -P options
Scan specific ports vs. host discovery probes (e.g. -Pn, -PE, -PA, -PS, -PU).
nmap -oN vs nmap -oX vs nmap -oG vs nmap -oA
Normal vs. XML vs. Grepable vs. all 3 output formats.
nmap -v vs nmap -V
Increase verbosity level vs. print utility version.
nmap -d vs nmap -D <decoys>
Increase debugging level vs. mask scan with decoy IPs.
nmap -n vs nmap -R
Never resolve reverse DNS vs. always resolve DNS for all targets.
nmap -F
Fast mode - only scan 100 most common ports (default is 1000).
nmap -O vs nmap -A
Enable OS detection vs. aggressive scan (OS, version, default scripts, traceroute).

🏓 Ping

ping -c <count>
Stop after sending count ECHO_REQUEST packets.
ping -w vs ping -W
Exit after a deadline in seconds vs. timeout to wait for response.
ping -t <ttl> vs ping -T <option>
Set IP Time-To-Live (hops) vs. set IP timestamp options.
ping -q vs ping -Q <tos>
Quiet output (summary only) vs. set Quality/Type of Service octet.
ping -b vs ping -B
Allow broadcast pinging vs. bind to specific source IP / lock path.
ping -d vs ping -D
Enable SO_DEBUG socket option vs. print Unix timestamp before each line.
ping -f vs ping -F
Flood ping (send packets as fast as they reply - root) vs. IPv6 flow label.
ping -a vs ping -A
Audible ping (beep on reply) vs. adaptive ping interval based on RTT.
ping -r vs ping -R
Bypass normal routing tables vs. record route (show IP hops).

🔍 Find

find . -name vs find . -iname
Case-sensitive vs. case-insensitive filename search.
find . -path vs find . -ipath
Case-sensitive vs. case-insensitive full path matching.
find . -regex vs find . -iregex
Case-sensitive vs. case-insensitive regular expression match.
find -P vs find -L vs find -H
Never follow symlinks (default) vs. always follow vs. follow command line arg symlinks only.
find . -type f
Find only regular files (use d for directories).
find . -size +50M
Find files larger than 50 Megabytes (use -10k for < 10 KB).
find . -mtime -7
Find files modified in the last 7 days (use -mmin -60 for < 60 min).
find . -perm 644
Find files with exact 644 octal permissions.
find . -maxdepth 2
Limit directory search depth to 2 levels.
find . -name "*.log" -delete
Find and immediately delete matching files.
find . -type f -exec chmod 644 {} +
Execute command on all found files efficiently using {} +.
find . -path "*/node_modules*" -prune -o -print
Prune/exclude specific directories (e.g. node_modules) from search.

🔍 Grep

grep -e <pat> vs grep -E
Specify match pattern vs. use Extended Regular Expressions (egrep).
grep -f <file> vs grep -F
Get patterns from file vs. treat patterns as Fixed strings (fgrep).
grep -i vs grep -I
Case-insensitive search vs. ignore/skip binary files.
grep -l vs grep -L
Print only names of files WITH matches vs. files WITHOUT matches.
grep -r vs grep -R
Recursive search vs. recursive search following symbolic links.
grep -h vs grep -H
Suppress file name prefixes on output vs. always print file name prefix.
grep -w vs grep -x
Match exact whole word only vs. match exact whole line only.
grep -v
Invert match: show lines that do NOT match the pattern.
grep -n vs grep -c
Prefix matching lines with line numbers vs. print only count of matching lines.
grep -A 3 vs grep -B 3 vs grep -C 3
Show context: 3 lines After vs. 3 lines Before vs. 3 lines around (Context).

📝 Sed

sed -e vs sed -E
Specify inline script expression vs. enable Extended Regular Expressions.
sed -i vs sed -I
In-place edit (overwrites original file) vs. standard-compatible/case-insensitive flags.
sed 's/old/new/g'
Replace ALL occurrences of 'old' with 'new' globally on each line.
sed '3d' vs sed '/^$/d'
Delete line 3 from output vs. delete all empty/blank lines.
sed -n '5p' vs sed -n '/pat/p'
Print ONLY line 5 (-n suppresses auto-print) vs. print lines matching 'pat'.
sed 's/^[ \t]*//'
Remove leading whitespace/tabs from all lines.

📊 Awk

awk -F':' vs awk -v x=1
Set custom field separator vs. assign external variable to use in script.
awk '{print $1, $NF}' file
Print the 1st column and the last (NF) column of each line.
awk 'NR>=2 && NR<=5' file
Print only lines (Record Numbers) 2 through 5.
awk '{sum += $1} END {print sum}' file
Sum values in the 1st column and print the total at the end.
awk '{print toupper($0)}' file
Convert all characters in the file to uppercase.

📡 Netcat

nc -l vs nc -L
Listen mode (server) vs. persistent listen mode (stays open after client disconnect).
nc -p <port> vs nc -P <user>
Specify local source port vs. specify proxy credentials/options.
nc -t vs nc -T <tos>
Enable RFC854 telnet negotiation vs. specify Type of Service (TOS) value.
nc -d vs nc -D
Do not read from stdin (detach) vs. enable socket debugging option.
nc -n vs nc -N
Skip DNS name resolution vs. shutdown socket after EOF on stdin.
nc -v vs nc -V
Verbose connection output vs. print netcat version info.
nc -u vs nc -vz
Use UDP mode vs. zero-I/O verbose port scan on a range.

🧵 Strings

strings -a vs strings -d
Scan entire file (all sections) vs. scan only initialized data sections.
strings -t <radix> vs strings -T <target>
Print offset before each string (o/d/x) vs. specify binary target format.
strings -n <length>
Set minimum printed sequence length (default is 4).
strings -e <enc>
Select character encoding (e.g. l for 16-bit little-endian).
strings -f
Print the name of the file before each found string.

🐍 Python

python -v vs python -V
Verbose trace of import statements vs. print python version and exit.
python -m <module> vs python -c <cmd>
Run library module as script (e.g., http.server) vs. execute string command.
python -i vs python -O
Enter interactive mode after script run vs. optimize generated bytecode (removes asserts).
python -m venv <dir>
Create an isolated virtual environment directory.

📦 Pip

pip -V vs pip --version
Print version of pip and exit (supports both case options).
pip install -r <file>
Install all package dependencies listed in a requirements file.
pip freeze > requirements.txt
Export all installed packages and their versions to a requirements file.
pip list vs pip show <pkg>
List all installed packages vs. show detailed info about a specific package.
